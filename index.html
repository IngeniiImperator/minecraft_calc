                    Why this runs outside the page

                    A web page cannot press mouse buttons in another program — browsers sandbox that on purpose. It's also exactly why "online autoclicker" sites are either fake or ask you to run a download you can't inspect.

                    So the clicker itself is a short Python script kept in this repository at tools/autoclicker/autoclicker.py: small enough to read before you run it, fully offline, no admin rights, no installer. This tab only checks your settings and writes the command line for it.

                      Fair play & safety

                      • The script starts paused and never clicks until you press the toggle key; the quit key or Ctrl+C in its terminal stops it dead.
                      • Clicks land in whichever window has focus, at the current cursor position — keep Minecraft focused while it runs, and set an auto-stop if you'll be away long.
                      • Many multiplayer servers ban autoclickers and AFK devices. Use it in singleplayer, on your own Realm, or where the rules explicitly allow it — checking is on you.
                      • Deliberately plain: fixed pace, no randomized "humanizing" jitter, no window targeting, no game hooks — it is a metronome for your mouse, nothing more.
